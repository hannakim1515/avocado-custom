# 미궁 수동 검증 체크리스트

미실행 항목이다. 운영 사본 또는 준비된 테스트 환경에서 서로 다른 두 계정/브라우저로 확인한다. E2E/UI 자동화는 실행하지 않았다.

## 준비

- [ ] 실제 DB preflight와 백업 복원 확인, migration/readiness 통과.
- [ ] 부분 migration/미전환 inventory에서 명확한 준비 오류, 아이템/효과 변경 없음.
- [ ] 일반 아이템/장착 장비/강화·메모 포함 아이템/영구 아이템/부활·치료 아이템 준비.
- [ ] A/K 연동 공격·방어·회복·스킬 설정과 HP 스탯 확인.

## 대기실 및 map

- [ ] 지역 연동 ON/OFF 모두 기존 출현 정책과 입장 위치 제약 유지.
- [ ] 최소/최대 인원, READY 전원 조건, 동시 출발 1회.
- [ ] WAITING 중 사용/구매/장착은 정상, 출발 시 실제 최신 재고만 격리.
- [ ] WAITING 퇴장/강퇴 후 재입장 가능. 출발 후 신규 및 이탈자 재입장 불가.
- [ ] 진행 중 출현 갱신/던전 비활성화 후에도 기존 참가자가 이어하기 가능.
- [ ] 다른 세션 동시 참가 및 승인되지 않은 캐릭터 차단.

## 탐험

- [ ] 여러 번 출발해 방·갈림길 범위/보스/출구 연결 확인.
- [ ] 미방문 방 데이터가 HTML에 노출되지 않고 방문 지도만 표시.
- [ ] 이동/조사 동시 클릭 시 한 행동만 적용, 뒤로 이동·재방문 결과 유지.
- [ ] 조사·보물·함정이 버튼 클릭 시 발동, 선택지별 결과 재실행 불가.
- [ ] NONE/TEXT/ITEM/TRAP/MONSTER/HEAL, 함정 ACTOR/ALL/RANDOM 확인.
- [ ] 방 아이템은 생존자에게만 지급되고 현재 미궁에서 즉시 사용 가능.
- [ ] 채팅은 행동과 별개, HTML 입력은 텍스트로 표시.

## 전투

- [ ] 일반 공격/방어/회복/스킬/아이템/대기 제출·수정, 타깃 선택 유지.
- [ ] 제한시간 있을 때 전원 제출만으로 종료하지 않음. 전원 제출 후 스킵 가능.
- [ ] 제한시간 NULL이면 전원 제출 즉시 처리. 미제출자는 deadline 후 대기 처리.
- [ ] 다른 기기/중복 POST의 같은 turn resolve 1회.
- [ ] 스킬 자원·쿨타임·강약점·몬스터 패턴·회피/도발·상태 적용을 기존 설정과 대조.
- [ ] 생존자 전원 도주 찬성 시 일반 행동보다 우선, 성공/실패 각 확인.
- [ ] 전투불능 행동 차단, 살아 있는 소유자의 부활만 가능, 부활자는 다음 턴 행동.
- [ ] 상태 중첩 대신 시간 갱신, 치료 대상, 턴 종료 감소 확인.
- [ ] 전원 사망/마지막 생존자 이탈은 실패 정산.

## Inventory 및 동시 요청

- [ ] 장비 테이블 참조 행과 장비(K)는 원본에 남음. 장비 스탯 효과 유지.
- [ ] 미사용 원본의 in_id·메모·옵션·개별 컬럼 그대로 복원.
- [ ] 사용한 원본 복원 안 됨. 내부 획득 미사용만 신규 추가, 사용한 내부 획득 추가 안 됨.
- [ ] 진행 중 상점/퀘스트 신규 보상은 일반 inventory에 보존되고 현재 미궁에 추가되지 않음.
- [ ] 판매→출발 / 출발→판매 양 순서: 하나만 해당 원본 사용, 포인트 중복 없음.
- [ ] 일반 사용→출발 / 출발→일반 사용: 효과 중복 없음.
- [ ] 동일 원본 동시 사용/판매 중 한 번만 소비.
- [ ] 제작/퀘스트 다중 재료와 출발 경쟁: 일부 재료만 소비되는 실패 없음.
- [ ] 전송과 출발 경쟁: 이중 소유권 없음.
- [ ] 타인 in_id/미궁 inventory_id/다른 ds_id/과거 turn 직접 요청 거절.
- [ ] SQL 실패/중단에서 InnoDB 회복 rollback, MyISAM REVIEW와 guard 유지.

## Boss / Clear / 정산

- [ ] 보스 사망 즉시 채팅·탈출만 허용, 같은 턴 후속 독 피해와 부활 불가.
- [ ] 출구 클리어/탈출 시 생존자만 독립 확률 보상, 별도 보스 드롭 없음.
- [ ] 클리어/실패/자진퇴장/강퇴/관리자 퇴장·종료에서 같은 정산 결과.
- [ ] 결과 새로고침/동시 종료/보상 재시도에도 원본·아이템·포인트 중복 없음.
- [ ] 원본 ID 충돌 시 기존 행 덮어쓰지 않고 정산 미완료 유지.
- [ ] 마이페이지 결과에 시작/종료, 참가자, 획득 보상과 로그 확인.

## 관리자 및 회귀

- [ ] 미궁 설정·공용 상태·부활/치료 아이템 저장 및 잘못된 입력 거절.
- [ ] 진행 세션/전투 턴/전체 지도/로그/READY/전투불능 상태 조회.
- [ ] 강제 성공·실패·퇴장, 기존 인스턴스 삭제 우회 차단.
- [ ] 진행 중 설정 변경이 기존 snapshot에 소급하지 않음. 제한시간은 다음 턴 적용.
- [ ] 기존 일반 전투·기존 진행 던전·일반 구매·사용·판매·전송·장착·제작·퀘스트 정상.
- [ ] 미완료 소비 저널 실제 효과 확인 후 복원/완료, 중복 복구 금지.
- [ ] 모바일에서 버튼·폼·지도·기록 가독성, 새로고침/재접속, 네트워크 실패 후 재시도 확인.
