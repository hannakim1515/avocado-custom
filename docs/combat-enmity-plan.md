# 도발과 위협 순위 기획안

상태: 기본 위협·도발·행동 예고 구현 완료. 탱커 태세·위협 이전은 후속 기획입니다.

## 현재 사용법

- `몬스터 관리 → 몬스터 스킬 제작`에서 **행동 준비 대사 / 모션 설명**을 입력합니다. 예: `거대한 팔을 들어 올린다.`
- 몬스터 작성폼에서 해당 스킬과 사용 주기를 등록하고, 던전·미궁·레이드에 그 몬스터를 불러옵니다.
- 새 전투에서는 기존 `monster_runtime.state` JSON에 개체별 `enmity`, `enmity_target`, `intent`를 보관합니다. 이번 기능에 새 테이블·컬럼·migration은 없습니다.
- 던전·미궁은 몬스터 토큰에 예고와 단일/전체/무작위 범위를 표시합니다. 선택한 몬스터의 상세 대사와 파티 위협 순위를 표시하며, 다른 몬스터도 기술·범위를 간단히 보여줍니다. 레이드는 기존 전투 기록에서 준비 대사를 확인합니다.
- 예고된 기술은 해당 턴에 유지합니다. HP 조건은 다음 준비 시점에 다시 평가합니다. 사망·행동 불가는 공격을 취소할 수 있으며, 도발은 **기술을 바꾸지 않고 단일 공격 대상**을 바꿉니다.
- 대응은 기존 방어·회피 스킬을 사용합니다. 위치 이동·공격 범위 칸은 추가하지 않았습니다.
- 실제 피해 ×1, 실제 HP 회복 ×0.5, 도발은 최고 위협 + max(10, 최고 위협 10%)입니다. 과회복과 MP 회복은 위협을 추가하지 않습니다.
- 던전 도발은 선택한 살아 있는 몬스터에게 적용합니다. 미궁은 현재 적에게, 레이드의 기존 자신/아군 도발은 해당 참가자를 교전 중 몬스터들의 위협 1위로 올립니다. 전체·무작위 공격은 도발을 무시합니다.
- 새 전투 스냅샷에만 적용합니다. 기존 스냅샷에 위협 활성화 표시가 없으면 기존 대상·행동 규칙을 유지합니다.

아래 태세·광역/이전 규칙은 후속 확장 제안입니다.

## 구현 전 코드에서 확인한 것

- 기존 스냅샷의 공용 몬스터 단일 공격은 무작위이며, 새 스냅샷은 살아 있는 위협 1위를 선택합니다.
- 기존 미궁 전투의 일부 경로에는 도발 효과를 가진 캐릭터에게 피해를 모으는 처리가 있습니다. 몬스터별 위협 누적·순위는 없습니다.
- 공용 몬스터 경로에도 적용할 수 있는 하나의 위협 규칙을 먼저 정하고, 던전·미궁·실시간 레이드에 같은 규칙으로 연결하는 것이 좋습니다.

## 제안하는 기본 규칙

몬스터 **개체마다** 참가자의 위협 수치를 보관합니다. 슬라임 A와 슬라임 B는 각기 다른 1위를 가질 수 있습니다. 아래 숫자는 이 게임의 초기 조정안입니다.

| 행동 | 위협 처리 |
| --- | --- |
| 피해 | 실제 HP 피해량 × 1을 맞은 몬스터에게 추가 |
| 회복 | 실제 HP 회복량 × 0.5를 교전 중인 살아 있는 몬스터들에게 균등 분배 |
| 탱커 태세 | 자신이 만드는 피해·회복 위협 × 5 |
| 단일 도발 | 대상 몬스터의 현재 최고 위협 + max(10, 최고 위협의 10%)로 자신의 위협 설정 |
| 광역 도발 | 각 살아 있는 몬스터에 단일 도발 규칙 적용. 별도 스킬로 제작 |
| 위협 이전 | 자신의 누적 위협 일부를 지정한 살아 있는 아군에게 이전. 2단계 확장 |

- 0 피해·과회복은 위협을 만들지 않습니다. 회피한 공격도 피해 위협을 만들지 않습니다.
- 일반 단일 공격은 살아 있는 위협 1위에게 향합니다.
- 동률이면 현재 공격 대상을 유지합니다. 모두 0이면 한 명을 뽑아 기본 대상으로 삼습니다.
- 전투불능·퇴장·도주한 참가자는 공격 대상 후보에서 제외합니다.
- 부활 시 위협은 0부터 시작합니다. 전투가 끝나면 해당 전투의 위협도 끝납니다.
- 도발은 순위를 올리는 행동입니다. 이후 다른 참가자의 위협이 더 높아지면 대상이 다시 바뀔 수 있습니다.
- **전체 공격은 전체에게, 무작위 지정 공격은 무작위로** 적용합니다. 도발로 광역 피해까지 탱커 한 명에게 합치지 않습니다.
- ‘다음 몬스터 턴까지 반드시 자신을 공격’하는 효과가 필요하면 도발과 별개의 강제 대상 효과로 구분합니다.

## 스킬과 관리자 설정

기존 스킬 효과 제작 폼에 다음 종류를 추가하는 방향입니다. 스킬 이름만으로 기능을 판단하지 않습니다.

- 위협 추가: 단일/전체 몬스터, 고정 수치 또는 피해 비례.
- 도발: 대상 몬스터의 위협 1위가 됨. 재사용 대기와 소모 자원은 기존 설정 사용.
- 탱커 태세: 위협 생성 배율, 지속시간 또는 해제 전까지 유지.
- 위협 이전: 대상 아군, 이전 비율.

몬스터 공격에는 일반 단일 대상 / 위협 무시 무작위 / 전체 대상의 정책을 구분합니다. 보스의 지정 대상 기믹은 위협 순위를 무시할 수 있게 설명을 표시합니다.

## 저장과 공용 연결

- 새 위협 전용 테이블을 만들지 않습니다.
- 기존 `monster_runtime.state` JSON에 `enmity`(참가자→수치)와 현재 공격 대상 값을 보관합니다.
- 개체 키는 기존 던전 runtime monster ID, 미궁 battle ID, 레이드 unit ID를 사용합니다. 몬스터 마스터 ID만으로 저장하면 같은 몬스터 여러 마리가 위협을 공유하므로 피해야 합니다.
- 실제 피해·회복이 확정된 뒤 위협을 올리고, 몬스터의 다음 행동에서 대상 선정에 반영합니다.
- 서버의 기존 살아 있는 대상·세션 소속 검증과 턴 트랜잭션 안에서 함께 처리합니다.
- 진행 중인 옛 세션에는 기존 규칙을 유지하고, 새 세션 스냅샷에서 위협 사용 여부를 확정합니다.

## 플레이 화면과 로그

- 선택한 몬스터의 위협 순위와 현재 공격 대상을 표시합니다.
- 탱커에게는 ‘위협 1위’, 나머지는 순위와 1위 대비 게이지를 표시합니다.
- 예: `아린 → 슬라임 A / 도발 · 위협 1위`.
- 공격 대상이 바뀌면 로그에 남깁니다. 관리자 전투 로그도 같은 이벤트를 읽습니다.

## 구현 순서와 확인

1. 단일 도발 + 몬스터별 위협 누적 + 일반 공격 대상 선정.
2. 탱커 태세와 UI 순위 표시.
3. 광역 도발·위협 이전·보스 예외.

확인할 사례: 같은 종류 여러 개체의 위협 분리, 도발 직후 1위, 피해로 순위 역전, 동률 유지, 전투불능/부활, 회복 위협 분배, 전체·무작위 공격 예외, MP/재사용 대기, 동시 제출, 기존 세션 유지.
